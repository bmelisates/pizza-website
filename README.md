## About

This project turns a provided design into a web page, focusing on HTML structure and CSS styling.

The page includes:

- Hero section
- Food categories
- Promotional cards
- Menu showcase
- Footer

This is a static interface and does not process orders.

## Technologies

- HTML5
- CSS3

## Getting Started

Clone the repository:

    git clone https://github.com/bmelisates/pizza-website.git

Open the project folder:

    cd pizza-website

Install dependencies:

    npm install

Start the development server:

    npm run dev
